# Testing: green-flat (nested inline work)

SCENARIO top-level work is accepted
GIVEN a function whose straight-line setup does computation at the top level
WHEN `green lint` runs
THEN no `green-flat` error is reported

SCENARIO pure worker is accepted
GIVEN a function with no control flow (a pure linear worker)
WHEN `green lint` runs
THEN no `green-flat` error is reported

SCENARIO thin control body is accepted
GIVEN a controller whose `if`/loop/`switch` body is a single glue statement
(a discarded call, prefix update, constant init, or call-result binding)
WHEN `green lint` runs
THEN no `green-flat` error is reported

SCENARIO inline computation inside a loop body is reported
GIVEN a loop body that computes a value inline (`s = s + i;`)
WHEN `green lint` runs
THEN a `green-flat` error is reported

SCENARIO inline computation inside a bare block is reported
GIVEN an explicit `{}` block that computes a value inline
WHEN `green lint` runs
THEN a `green-flat` error is reported

SCENARIO more than one glue statement in a control body is reported
GIVEN a loop body that stacks two glue statements in a straight-line run
WHEN `green lint` runs
THEN a `green-flat` error is reported

SCENARIO a thin if body with a single glue call is accepted
GIVEN an `if` body that makes one discarded worker call
WHEN `green lint` runs
THEN no `green-flat` error is reported

SCENARIO a thin if/else pair with one glue per branch is accepted
GIVEN an `if` that binds a call result and an `else` that assigns a constant
WHEN `green lint` runs
THEN no `green-flat` error is reported

SCENARIO a thin while body with a single prefix update is accepted

WHEN `green lint` runs
THEN no `green-flat` error is reported

SCENARIO a thin switch with one glue per case is accepted

WHEN `green lint` runs
THEN no `green-flat` error is reported

SCENARIO a thin bare block with a single assignment is accepted

WHEN `green lint` runs
THEN no `green-flat` error is reported

SCENARIO a controller delegating to a pure worker is accepted
GIVEN a loop whose body is a single call to a worker that does the computation
WHEN `green lint` runs
THEN no `green-flat` error is reported

SCENARIO nested thin control bodies are accepted
